# Cardinal Market (Cardinal-Ecommerce)
A Facebook-Marketplace-style site for UIW students. CIS 2368 Midterm - Sandbox Website.

## Team & pages
| Person | Page(s) | Own files |
|---|---|---|
| Isabella | `index.html` (Home), `account.html` | `css/isabella.css`, `js/isabella.js` |
| Nathan | `listings.html` (Browse) | `css/nathan.css`, `js/nathan.js` |
| Maria | `item.html` (Item detail) | `css/maria.css`, `js/maria.js` |
| Sophia | `sell.html` (Sell form) | `css/sophia.css`, `js/sophia.js` |

Shared (don't edit alone): `css/main.css`, `js/main.js`, `images/`.

## Folder layout (must stay this way for the zip)
```
sandbox/
  index.html  listings.html  item.html  sell.html  account.html
  css/   main.css + one css file per person
  js/    main.js  + one js file per person
  images/
```

## Submitting
Zip the **sandbox** folder (right-click -> Compress) and submit. The PowerPoint (10%) needs screenshots of code and the site plus a demo.
